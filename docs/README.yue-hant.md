Scinoephile 係一個用嚟處理中英文雙語字幕嘅套件，重點係將分開嘅中文同英文字幕結合成同步嘅雙語字幕。

## 安裝

使用 Python 3.14 同 uv。OCR 需要由原始碼編譯 Paddle；CPU 同 Windows CUDA 環境嘅設定請睇
[Paddle 原始碼編譯指南](PADDLE_SOURCE.md)。
